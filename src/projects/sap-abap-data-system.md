## Overview

Developed as part of the intensive bootcamp program with **Techno India Group & AWS Academy**, this project explores enterprise business logic programming using SAP Advanced Business Application Programming (ABAP).

The project implements classical and interactive report generators, relational data dictionary modeling, and efficient querying of transactional ERP datasets.

## Key Technical Components

- **Data Dictionary (SE11)**: Created custom transparent tables, domains, data elements, and foreign key relationships with referential integrity.
- **Internal Tables Operations**: Designed data manipulation pipelines utilizing hashed, sorted, and standard internal tables to process large batch selections efficiently.
- **OpenSQL Querying**: Implemented selective database access patterns with `FOR ALL ENTRIES` and aggregate operations to eliminate N+1 query bottlenecks.

## Practical Outcomes

This practical coursework provided an in-depth understanding of how global corporations model enterprise data schemas, process bulk payroll and logistics data, and enforce strict database consistency.
