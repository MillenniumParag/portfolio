Google & Bing Recommended Image Sizes

Images uploaded through Decap CMS are automatically compressed in-browser and optimized at build time. For the best rankings on Google Discover, Bing snippet previews, and social cards, aim for the following dimensions:

Placement Dimensions Ratio Max Weight
OpenGraph / Social / Blog Cover 1200 x 630 px 1.91:1 < 200 KB
Project Showcase Card 1200 x 800 px 3:2 < 150 KB
Author Avatar / Profile 400 x 400 px 1:1 < 50 KB
Inline Article Figures Max 1600 px w Responsive < 200 KB
Pro-tip: Keep images in WebP or compressed JPEG. The automated compression pipeline handles scaling and stripping metadata to keep Core Web Vitals green.
